Quick start

Backend (development)
1. cd backend
2. python -m venv .venv && .venv\Scripts\activate  (or source .venv/bin/activate on Unix)
3. pip install -r requirements.txt
4. Copy .env.example to .env and set keys
5. docker compose -f ../infra/docker-compose.yml up -d
6. uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Android
1. Open the android/ folder in Android Studio (Gradle will download the wrapper).
2. Copy local.properties.example to local.properties; set sdk.dir and PICOVOICE_ACCESS_KEY.
3. Run on a device with USB debugging; complete onboarding (HTTPS URL must match your backend).

See TESTING.txt for the manual E2E checklist.
